# Installation Guide

Deadlock Mod Manager is available for Windows and Linux. Choose your preferred installation method below.

![Installation Process](/assets/download-page.png)

## Download Options

### Option 1: Direct Download (Recommended)

The easiest way to install Deadlock Mod Manager is to download the latest release directly from our website:

[Download Deadlock Mod Manager](https://deadlockmods.app/download)

### Optional CEF Builds

Some releases also include builds using Chromium Embedded Framework (CEF) instead of the standard system webview. Look for release assets with a `-cef` suffix, such as `-cef-setup.exe`, `-cef.deb`, or `deadlock-mod-manager-cef.flatpak`, when available. On Ubuntu/Debian, the CEF build is also available from the [APT repository](#ubuntudebian-apt).

CEF is an alternate runtime for the same manager features. Use the release notes to decide which build suits your system, especially when troubleshooting webview rendering. Availability varies by release and platform. Avoid running multiple builds against the same game installation at once.

### Windows standalone executable

Download `Deadlock.Mod.Manager_<version>_x64-portable.exe` from GitHub Releases and run it directly without installing DMM. Stable, nightly, and test releases include this download alongside the installer.

The standalone executable uses the same default AppData locations as the installed app, including existing settings and downloaded mods. Microsoft Edge WebView2 Runtime must already be installed.

To keep using DMM without installation, download the newer standalone executable and replace the old one after closing DMM. The in-app updater uses the Windows installer. Running DMM also registers its deep-link protocols, so keep the executable at a stable location for browser install links.

### Option 3: Package Managers

For users who prefer package managers, Deadlock Mod Manager is available through several official repositories:

#### Windows (winget)

<Callout type='warning' title='Winget'>
  Pushing new versions to winget is a work in progress. Microsoft takes a while
  to approve new versions.
</Callout>

```bash
winget install --id=Stormix.DeadlockModManager
```

#### Ubuntu/Debian (APT)

```bash
# Add the repository signing key
curl -fsSL https://apt.deadlockmods.app/key.gpg \
  | sudo tee /usr/share/keyrings/deadlock-mod-manager.gpg > /dev/null

# Add the repository
echo "deb [arch=amd64 signed-by=/usr/share/keyrings/deadlock-mod-manager.gpg] https://apt.deadlockmods.app stable main" \
  | sudo tee /etc/apt/sources.list.d/deadlock-mod-manager.list

# Install
sudo apt update
sudo apt install deadlock-mod-manager
```

New stable releases arrive through `sudo apt update && sudo apt upgrade`. The repository only contains stable x86_64 builds; nightly builds remain available from GitHub Releases.

To use the [CEF build](#optional-cef-builds) instead, replace `main` with `cef` at the end of the repository line, then reinstall:

```bash
echo "deb [arch=amd64 signed-by=/usr/share/keyrings/deadlock-mod-manager.gpg] https://apt.deadlockmods.app stable cef" \
  | sudo tee /etc/apt/sources.list.d/deadlock-mod-manager.list

sudo apt update
sudo apt install --reinstall deadlock-mod-manager
```

Both builds install the same `deadlock-mod-manager` package, so enable only one of `main` or `cef`. To switch back, put `main` back and reinstall the same way.

<Callout type='info' title='Supported versions'>
  Packages are built on Ubuntu 24.04. Older releases such as Ubuntu 22.04 or
  Debian 12 may install the package but fail to start because of older system
  libraries.
</Callout>

#### Arch Linux (AUR)

```bash
# Latest stable release
yay -S deadlock-modmanager

# Latest development build
yay -S deadlock-modmanager-git
```

#### nixpkgs

```bash
# Run in your shell
nix-shell -p deadlock-mod-manager --run deadlock-mod-manager

# Experimental nix flakes version
nix shell nixpkgs#deadlock-mod-manager -c deadlock-mod-manager
```

```nix
# configuration.nix
environment.systemPackages = with pkgs; [
  deadlock-mod-manager
];
```

#### Gentoo

Available via the third-party [`::deftera`](https://github.com/Deftera186/deftera-overlay) overlay.

```bash
# Enable the overlay
sudo eselect repository add deftera git https://github.com/Deftera186/deftera-overlay.git
sudo emaint sync --repo deftera

# Prebuilt binary (recommended)
sudo emerge -av games-util/deadlock-modmanager-bin

# Or build from source
sudo emerge -av games-util/deadlock-modmanager
```

More package managers will be added in the future. If you would like to maintain a package manager for Deadlock Mod Manager, please contact us on [Discord](https://deadlockmods.app/discord).

## Platform-Specific Installation

### Windows Installation

1. **Download the installer** (.exe file) from the releases page
2. **Run the installer** by double-clicking the downloaded file

<Callout type='warning' title='Windows Security Warning'>
  You might see a prompt saying "Windows has protected your PC" due to the app
  not being code-signed yet. Click **More Info** and then **Run Anyway** to
  proceed with the installation.
</Callout>

3. **Follow the setup wizard** to choose installation location and options
4. **Launch the application** from the Start Menu or desktop shortcut

### Linux Installation

<Callout type="warn" title="Linux Support - Limited">

Linux support is provided on a **best-effort basis**. Due to a lack of contributors with Linux expertise and the maintainer's limited experience distributing software across the many Linux distributions, you may encounter packaging issues, missing dependencies, or platform-specific bugs.

If you're a Linux user and want to help improve support, contributions are very welcome! Please reach out on [Discord](https://deadlockmods.app/discord) or open a PR on [GitHub](https://github.com/deadlock-mod-manager/deadlock-mod-manager).

</Callout>

#### Ubuntu/Debian (.deb package)

To receive updates through `apt`, use the [APT repository](#ubuntudebian-apt) instead.

```bash
# Download the .deb file, then install
sudo apt install ./Deadlock.Mod.Manager_*_amd64.deb
```

#### Flatpak

```bash
# Install from the Flatpak bundle
flatpak install ./deadlock-mod-manager-*.flatpak

# Or, once published on Flathub:
flatpak install flathub dev.stormix.deadlock-mod-manager
```

On Steam Deck or other Linux systems, if the Flatpak crashes when you select the game folder, see [community-reported Flatpak filesystem workaround](./troubleshooting#flatpak-crashes-when-selecting-the-game-folder).

#### Arch Linux (AUR)

```bash
# Using yay (recommended)
yay -S deadlock-modmanager

# Or using makepkg directly
git clone https://aur.archlinux.org/deadlock-modmanager.git
cd deadlock-modmanager
makepkg -si
```

<Callout type="info" title="Linux Compatibility Note">
If the Flatpak application opens to a grey or blank screen, particularly with an NVIDIA GPU, follow the [community-reported Flatpak rendering workaround](./troubleshooting#flatpak-opens-to-a-grey-screen-on-nvidia). Automatic GPU detection may fail inside the Flatpak sandbox.

For non-Flatpak installs (.deb / AUR / RPM), you can apply it manually:

```bash
WEBKIT_DISABLE_DMABUF_RENDERER=1 deadlock-mod-manager
```

AUR users have this automatically handled via the `.desktop` file.

</Callout>

## Post-Installation Setup

After installing Deadlock Mod Manager, you'll need to complete the initial setup:

### First Launch

1. **Launch the application** from your desktop or applications menu
2. **Grant necessary permissions** when prompted (file system access for mod installation)
3. The app will attempt to **automatically detect your Deadlock installation**

### Verify Installation

To ensure everything is working correctly:

![First Launch](/assets/verify.png)

1. **Check the bottom status bar** - API should be online (green) and the game should be "ready".
2. **Browse the Mods tab** - you should see available mods loading
3. **Test downloading a mod** - try installing a simple mod to verify functionality

## Troubleshooting Installation Issues

### Common Issues

#### "App won't start" or crashes on launch

- **Windows**: Run as administrator once, then normally
- **Linux**: Ensure all dependencies are installed (`sudo apt install libwebkit2gtk-4.0-dev` on Ubuntu)

#### "Cannot find Deadlock installation"

- Verify Deadlock is installed through Steam
- Check that the game has been launched at least once
- If the game is still not detected, please open an issue on [GitHub](https://github.com/deadlock-mod-manager/deadlock-mod-manager/issues) with your system info and the steps you took to install the game.

#### Download/installation issues

- Check your internet connection
- Verify you have write permissions to the Deadlock directory
- Try running the app as administrator (Windows) or with sudo (Linux)

  <Callout type='warning' title='Region-Specific Issues'>
    Users in certain regions (Brazil, China, Iran, Russia, Turkey, Ukraine) may
    need to use a VPN to access mod downloads due to upstream provider
    restrictions from sites like GameBanana
  </Callout>

### Getting Help

If you encounter issues not covered here:

1. **Check existing issues** on [GitHub Issues](https://github.com/deadlock-mod-manager/deadlock-mod-manager/issues)
2. **Join our Discord** for community support: [Discord Server](https://discord.gg/WbFNt8CCr8)
3. **Create a new issue** with details about your system and the problem
