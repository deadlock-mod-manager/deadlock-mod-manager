# Features Overview

Deadlock Mod Manager helps you discover, download, and manage mods, customize heroes, and launch Deadlock with your chosen setup.

## Mod Discovery

![Loaded Mods Store showing section tabs, filters, favorites, and sorting](/assets/v2-mods-store.png)

Open **Mods Store** to browse the Mods Store. Switch between mods, sounds, and works in progress (WIPs). With **Custom Maps** enabled, maps also have their own section.

- Search by name, author, or description, and save favorites for later.
- Include or exclude categories and heroes, and filter outdated content.
- Sort by downloads, rating, release date, or last update.
- Use the **Added** filter to narrow results by when submissions were published.
- Open a mod to inspect its description, media, available downloads, requirements, and author changelog when provided.

The catalog is cached locally and refreshed from GameBanana. Downloading new files and refreshing listings require an internet connection.

## Installation and Downloads

Download a mod, choose its files or variants, then enable it in **Mods Library**. The Downloads page shows progress and lets you pause, resume, or retry downloads. You can also add local mods rather than downloading them from the store.

Mods with several VPK files or sharded VPK archives are supported. Select the variants you want when installing; the manager handles the associated files.

See [Getting Started](/using-mod-manager/getting-started) for installation and launch instructions.

## Managing Your Library

From **Mods Library**, you can enable or disable mods, uninstall them, change load order, analyze existing local addons, and check for updates. When updates are available, review the files to install in the batch update dialog.

Use **Reinstall Mod** on a downloaded mod to rebuild its installation from its downloaded files. For backups and recovery tools, see [Updating Mods and Backups](/using-mod-manager/getting-started#updating-mods).

See [Mods Library and Files](/using-mod-manager/library) for local imports, favorites, variants, conflict warnings, VPK replacement, and reporting broken mods.

## Hero Skins and Customization

**Hero Skins** groups downloaded skins by hero and lets you choose the active skin or return to the default appearance. You can manage variants, assign unrecognized mods to a hero, and toggle sounds and other hero mods separately.

**Crosshairs** provides a crosshair editor and saved configurations. **Autoexec Config** lets you edit startup console commands and browse a command library. Plugins provide themes and other interface customization.

See [Customization](/using-mod-manager/customization) for instructions, including the Mod Foundry skin editor.

## Profiles and Sharing

Profiles keep separate mod setups, including enabled mods and load order. Create a profile, activate it, and manage its mods in Mods Library. Share a Profile ID with friends or preview and import one they send you.

See [Profiles and Sharing](/using-mod-manager/profiles) for the workflow and sharing limitations.

## Community Servers and Player Stats

The **Server Browser** lists community servers with player counts and ping information. Its join flow checks required maps and addons before connecting.

**Stats** offers an overview of your matches, hero and item statistics, squad information, and a live-match view. Optional **Match Data Sharing** can contribute missing match data to deadlock-api.

See [Servers and Stats](/using-mod-manager/community) for setup and privacy details.

## Settings and Experimental Features

![Experimental feature settings](/assets/v2-experimental.png)

See [Settings and Recovery](/using-mod-manager/settings) for launch options, game configuration, Discord presence, networking, hero detection, content controls, and recovery tools.

Settings has a search field to help find options. You can configure language, appearance, content filtering, network options, backups, and logging. **Privacy & Content** includes NSFW filtering and a reset for saved per-item choices.

<Callout type='info' title='Feature availability'>
  Open **Settings → Experimental** to control Custom Maps, Server Browser, Mod
  Foundry, Player Stats, Profile Management, and Profile Sharing. Maps and
  Server Browser are off by default; the other switches are on by default for a
  fresh setup. Your saved preferences may differ. These switches are local and
  do not require signing in. Experimental features may change between releases.
</Callout>

Stable and nightly builds can differ. See [Update Channels](/using-mod-manager/update-channels) if a feature described here is missing from your installed version.
