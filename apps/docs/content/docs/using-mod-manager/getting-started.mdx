# Getting Started

After [installing the manager](/using-mod-manager/installation), configure your game path and install your first mod.

![Dashboard with profile selector, launch buttons, navigation, and status bar](/assets/v2-dashboard.png)

[Interface and Status Icons](/using-mod-manager/interface) explains the controls, counters, and bottom-bar indicators shown here.

## First time setup

1. Let the manager detect your Deadlock installation.
2. Review the detected path. If it is missing or incorrect, browse to your installation.
3. Review existing addons and your network preferences.
4. Choose your analytics preference and read the separate match-sharing consent before enabling it.
5. Complete setup and open the Dashboard.

You can change the game path under **Settings → Game**. If Steam detection finds the wrong installation, set a custom Steam path. Use **Reset Onboarding** in the information section of Settings to repeat the wizard.

### Game configuration

Deadlock's `gameinfo.gi` controls which content folders are loaded. The manager adjusts that configuration for modded and vanilla launches. Under **Settings → Game**, inspect its status and use validation, backup, restore, or reset controls when needed.

If you previously edited `gameinfo.gi` manually, preserve a copy before resetting it or using Steam's **Verify integrity of game files**. Review [Settings and Recovery](/using-mod-manager/settings#game-setup-and-launch) before changing configuration.

![Game path and gameinfo configuration panel](/assets/v2-game-settings.png)

## Already have mods installed?

Open **Mods Library** and choose **Analyze Local Addons** to scan existing addon files and try to match them with catalog submissions. Review the results before managing the detected mods.

Unrecognized files may be custom or modified versions. Use **Review files** in the unrecognized-addons alert to inspect them, or **Add Local Mod** to import your files. See [Mods Library and Files](/using-mod-manager/library#unrecognized-addons).

## Understanding the interface

Use the sidebar to open the main pages:

- **Dashboard**: Featured and recent mods, announcements, release information, and game patch notes.
- **Mods Store**: Browse mods, sounds, and works in progress.
- **Mods Library**: Manage downloads and enabled mods in the active profile.
- **Downloads**: Monitor progress and pause, resume, or retry downloads.
- **Hero Skins**, **Crosshairs**, and **Autoexec Config**: Customize your game.
- **Settings**: Search and configure preferences.

Maps, Server Browser, Mod Foundry, and Stats depend on switches under **Settings → Experimental**. See [Features](/using-mod-manager/features#settings-and-experimental-features) for availability.

### Mods browser

In Mods Store, choose a section and search by name, author, or description. Include or exclude heroes and categories, filter outdated listings, use **Added** to filter by publication date, or narrow results to favorites. Sort by downloads, rating, release date, or last update.

NSFW visibility and blur are controlled under **Settings → Privacy**. Refreshing the locally cached catalog and downloading new files require an internet connection.

![Mods Store with section tabs, filters, sorting, and mod cards](/assets/v2-mods-store.png)

### Individual mod pages

A mod listing includes:

- Description, author, category, dates, and download statistics.
- Download files and variants.
- Requirements and dependencies.
- Image/video gallery and audio preview when available.
- Author changelog, original-post link, and support-author links when provided.
- Installed VPK filenames and file-management controls for local installations.

![Enhanced QuickBuy detail page showing author, listing statistics, and download action](/assets/v2-mod-detail.png)

## Installing your first mod

1. Open Mods Store and choose a mod.
2. Review its description, requirements, and download files.
3. Choose **Download Mod** and select the files you want when prompted.
4. Wait for downloading and extraction to finish.
5. Enable the downloaded mod in Mods Library, selecting its install files or variants if requested.
6. Use **Launch modded** to test your setup in Deadlock.

> **Screenshot pending:** Download selection and installed-mod enable controls.

Downloaded mods stay disabled until you enable them. If a hero-conflict warning appears, choose whether to swap the existing mod or keep both.

### Monitoring downloads

Open **Downloads** to inspect progress, speed, and extraction status. Use **Pause** and **Resume** for a download you want to defer, or **Retry** after a failure.

> **Screenshot pending:** Download card showing progress and pause/resume/retry actions.

### Verifying installation

Check the mod's status and installed files in Mods Library or its detail page. Then launch modded Deadlock and verify the result in-game. If Deadlock was already running when you changed files, restart it so it loads the new setup.

## Managing your mods

### Enable/disable mods

Toggle mods from Mods Library. Disabled mods remain downloaded for later use. **Disable all mods** turns off the active profile's setup without toggling entries individually.

Use [profiles](/using-mod-manager/profiles) for separate setups and [Hero Skins](/using-mod-manager/customization#hero-skins) to choose a skin by hero.

### Changing load order

Choose **Change Mods Order** in Mods Library, drag the entries into the desired order, and save. This controls the ordering of game-visible addon files. Load order determines which replacement takes priority. Conflicting mods may still fail to work together.

> **Screenshot pending:** Change Mods Order dialog.

### Updating mods

1. Choose **Check for updates** in Mods Library.
2. Open the available-updates action when updates are found.
3. Review the files or variants to install and start the batch update.
4. Review the result and restart Deadlock before testing.

You can also use **Update Mod** on a detail page. **Force Update**, when available, opens the update flow without requiring a detected newer version. Updates depend on the author publishing files; they do not guarantee compatibility with the latest game patch.

### Reinstalling a mod

If installed files are missing or damaged, use **Reinstall Mod** from the mod's context menu or detail page to rebuild the installation from its downloaded files.

### Uninstalling mods

Choose the mod's uninstall action and review the confirmation. Disable it instead if you want to keep the download for later. See [Mods Library and Files](/using-mod-manager/library) for local imports, variants, VPK replacement, and other file operations.

### Backups and recovery

Open **Settings → Backups** to create or restore an addons backup and configure automatic backups and retention. Preserve a backup before changing a setup you want to keep.

**Settings → Tools** offers folder shortcuts and recovery actions. Clearing caches, resetting state, and deleting mod data have different effects. Read [Settings and Recovery](/using-mod-manager/settings#backups-and-recovery) and each confirmation before using them.

### Game updates and patch notes

The manager warns when Steam is updating Deadlock. Let it finish before launching. Read patch notes on the Dashboard or from the game-update notice. Test your mods after a game update and disable any that no longer work.
