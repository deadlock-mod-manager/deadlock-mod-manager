# Profiles and Sharing

Each profile has its own mods, enabled variants, and load order. You can keep one setup for testing and another for playing with friends.

## Enable profile features

Open **Settings → Experimental** and enable **Profile Management**. Enable **Profile Sharing** as well if you want to share or import setups. Both are on by default in a new installation. Existing installations keep their saved preferences.

## Create and switch profiles

![Manage Profiles dialog with the default profile and create and import actions](/assets/v2-profiles.png)

1. Click the active profile name in the app's header to open **Manage Profiles**.
2. Choose **Create New Profile** and enter a unique name and an optional description.
3. Create the profile, then choose **Activate** for the setup you want to use.
4. Open **Mods Library** to add and enable mods for that profile.
5. Launch modded Deadlock to use the active setup.

Check the active profile before changing mods or load order. Close Deadlock before switching setups so the next launch loads the intended files.

Manage Profiles lets you rename, edit, or delete profiles. For the default profile, you can only edit the description. Check the confirmation before deleting a profile.

## Share a profile

1. Activate the profile you want to share and enable the mods you want included.
2. Choose **Share Profile**.
3. Wait for the Profile ID to appear, then choose **Copy** and send the ID to your friend.

Sharing requires an internet connection and at least one enabled mod.

<Callout type='info' title='What a Profile ID contains'>
  A Profile ID describes a setup; it does not upload your local VPK files. The
  recipient needs access to the referenced downloads. Keep separate backups of
  local or custom mods.
</Callout>

## Import a shared profile

![Import Profile dialog waiting for a shared profile ID](/assets/v2-profile-import.png)

1. Open Manage Profiles and choose **Import Profile**.
2. Paste the Profile ID and choose **Import** to load a preview.
3. Review the included mods. Unavailable submissions are marked in the preview.
4. Choose **Create New Profile** to keep the setup separate, or **Override Active Profile** to update your current setup.
5. Complete the import and inspect Mods Library and Downloads before launching.

Older shared profiles can contain an ID that exists as both a GameBanana mod and a sound. If prompted, choose the matching submission type before continuing.

<Callout type='warning' title='Check the import destination'>
  Override Active Profile changes your current setup. Create a new profile if
  you want to preserve it. If a download is unavailable, you may be unable to
  recreate the full setup.
</Callout>
