# Interface and Status Icons

![Dashboard with profile and launch controls, sidebar navigation, featured mod, summary counts, and bottom status bar](/assets/v2-dashboard.png)

This screenshot shows the Dashboard with experimental features enabled. The pages you see depend on your settings, build, and window size. The highlighted sidebar entry is the current page. Scroll the sidebar or page to see entries and content below the window.

## Top bar

| Control                                                | What it does                                                                                                                                                                                                           |
| ------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Default Profile**, people icon, and up/down chevrons | Shows the active profile. Click to open Manage Profiles and create, import, or activate another setup when Profile Management is enabled.                                                                              |
| Share icon beside the profile                          | Opens the active profile's sharing dialog when Profile Sharing is enabled. Review the profile before publishing it.                                                                                                    |
| **Launch without mods**, outlined play icon            | Starts Deadlock with the vanilla configuration. Your downloaded mods remain available in the manager.                                                                                                                  |
| **Launch modded**, filled play icon                    | Starts Deadlock with the active profile's enabled mods. An enabled-mod count appears when there are enabled mods. While Deadlock is running, this becomes **Stop Game**. Launch controls require a detected game path. |
| **Sign In**, arrow icon                                | Opens sign-in for your manager account. After signing in, use this area to open your user menu. Stats uses a separate Steam account.                                                                                   |
| Minus, square, and X                                   | Minimize, maximize or restore, and close the manager window.                                                                                                                                                           |

The app logo, **Deadlock Mod Manager**, version (**v2.0.0** here), and author credit identify the build. The author credit opens the author's GitHub page. Nightly builds also show a Nightly badge with the full version in its tooltip.

## Sidebar

The sidebar groups pages under section headings.

| Section        | Entry and icon                       | What it opens                                                                                                          |
| -------------- | ------------------------------------ | ---------------------------------------------------------------------------------------------------------------------- |
| General        | **Dashboard** (house)                | Featured, trending, and recent mods, announcements, release information, and patch notes.                              |
| General        | **Downloads** (download tray)        | Download/extraction progress and pause, resume, or retry controls.                                                     |
| General        | **Settings** (gear)                  | Game setup, preferences, plugins, privacy, backups, and recovery tools.                                                |
| Mods           | **Mods Library** (cube, count badge) | Downloaded mods and the active profile's setup. The badge is the library count; **0** here means the library is empty. |
| Mods           | **Mods Store** (magnifying glass)    | Search and browse catalog mods, sounds, and works in progress.                                                         |
| Mods           | **Maps** (folded map)                | Custom-map listings, available when Custom Maps is enabled.                                                            |
| Custom Servers | **Server Browser** (server rack)     | Community servers, filters, player lists, and required content, available when Server Browser is enabled.              |
| Customization  | **Crosshairs** (reticle)             | Community crosshairs and the crosshair editor/import flow.                                                             |
| Customization  | **Hero Skins** (shirt)               | Skin selection, hero associations, and optional 3D previews.                                                           |
| Customization  | **Mod Foundry** (hammer)             | Import a hero skin and edit its assets, paint, cards, or sounds; available when Mod Foundry is enabled.                |
| Customization  | **Autoexec Config** (document)       | Command library and the autoexec.cfg editor.                                                                           |
| Customization  | **Performance** (gauge)              | Community `gameinfo.gi` performance configs and their settings editor, available when Performance Configs is enabled.  |
| Customization  | **Stats** (chart)                    | Player statistics and match details, available when Player Stats is enabled.                                           |
| Developer      | **Developer** (code brackets)        | Developer utilities when developer mode is enabled.                                                                    |
| Developer      | **Debug** (bug)                      | Diagnostic tools when developer mode is enabled.                                                                       |
| Developer      | **Documentation** (question mark)    | Opens the documentation site.                                                                                          |
| Sidebar footer | **Collapse menu** (left arrow)       | Reduces the sidebar to icons; use the expand control to restore labels.                                                |

See [Features](/using-mod-manager/features#settings-and-experimental-features) to enable optional pages.

## Dashboard content

| Item                                     | Meaning or action                                                                                                             |
| ---------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| **Dashboard** title and subtitle         | Identifies the page and its discovery content.                                                                                |
| **Featured Mod of the Week** banner      | Highlights a catalog submission. **Yamato remodel** is the title in this example; the author and description appear below it. |
| **SKINS** label                          | The featured mod's category.                                                                                                  |
| Download-tray icon and **220,162**       | The featured listing's download count, not your local download queue.                                                         |
| Heart icon and **253**                   | The listing's likes from its source, not your personal favorites count.                                                       |
| **View Mod** and right arrow             | Opens the featured listing's detail page.                                                                                     |
| **Installed**, cube icon, **0**          | Number of mods in the installed/enabled state in the active setup. Downloaded but disabled mods are not included.             |
| **Updates**, circular-arrows icon, **0** | Number of downloaded mods with available updates. This is separate from manager application updates.                          |
| **In Queue**, download-tray icon, **0**  | Number of mods downloading or paused. Extraction is counted separately by the bottom bar.                                     |
| **Manage Profiles**, people icon         | Opens the same profile manager as the top-bar profile selector.                                                               |
| **Browse Store** and right arrow         | Opens Mods Store.                                                                                                             |
| **Trending Skins**, rising-arrow icon    | A row of popular skin listings. Open a card to inspect the mod. Additional discovery sections are below the fold.             |
| Left/right chevrons beside the row       | Move through the row's cards.                                                                                                 |
| **See all** and right arrow              | Opens the store with the corresponding discovery filters.                                                                     |
| **NSFW** badge on a card                 | Marks adult content. Visibility and preview blur follow Settings → Privacy and saved per-item choices.                        |

## Bottom bar: status icons

Read the icons **from left to right after "Status:"**. Hover an icon for its current explanation; color alone cannot distinguish every state. Healthy indicators use a pale gold accent in this bar, including with custom themes.

| Icon                                           | Meaning                              | States                                                                                                                                                                                                                                                                                         |
| ---------------------------------------------- | ------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Wi-Fi signal                                   | Manager API health                   | Full signal/pale gold: healthy. Reduced signal/yellow: degraded. Signal with X/red: offline. Slashed signal/muted: status unknown. This checks the API, not your computer's Wi-Fi connection.                                                                                                  |
| Padlock                                        | Authentication-service health        | Pale gold: service online. Red: service offline. Muted: unknown. You can still be signed out when this service is online, as the **Sign In** button shows here.                                                                                                                                |
| Drive/server stack                             | Access to the configured game folder | Pale gold: writable. Red warning triangle: read-only. Muted stack: unknown. Appears only when a game path is configured.                                                                                                                                                                       |
| Broadcast waves around a dot                   | Server relay network                 | Pale gold: all reported relays healthy. Yellow: some healthy. Red: none healthy. Appears when Server Browser is enabled and relay information is available. Click for each relay's region, health, and latency. Individual relay dots are green (online), amber (degraded), or rose (offline). |
| Circled checkmark, or spinning circular arrows | Hero detection for downloaded mods   | Pale gold check: idle. Blue spinning arrows: scanning. Hover during a scan to see the mod, progress, and number of entries being processed. An idle check is not a mod-compatibility guarantee.                                                                                                |
| Discord controller-shaped logo                 | Discord game presence                | Muted: disabled. Pale gold: waiting for Deadlock or connected. Hover to see which state applies. Blue: connecting. Red: connection error. Configure it under Settings → Discord.                                                                                                               |

In this screenshot, the API and authentication service are online, the game folder is writable, all reported relays are healthy, hero detection is idle, and Discord presence is enabled. Hover the Discord icon to distinguish waiting from connected.

Other controls can appear beside these indicators:

| Item                                          | Meaning or action                                                                                                                                                                        |
| --------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Blue pulsing download icon and count          | Mods currently downloading or extracting. Hidden when the count is zero.                                                                                                                 |
| Amber download icon and count                 | Paused downloads. Hidden when the count is zero.                                                                                                                                         |
| **Game not detected** badge                   | No game path is configured. Open Settings → Game before launching.                                                                                                                       |
| Speaker and **VOLUME: 50%**                   | Volume for audio previews in the manager. Click to open the slider. The speaker is muted at 0%, low below 50%, and high from 50% upward; this does not change Deadlock's in-game volume. |
| Cloud-download icon and **Check for Updates** | Checks for a new manager build. When an update is available, a badge appears and the action becomes **Install Update**. The button is disabled while checking or installing.             |

For fixes related to service health, paths, downloads, and launching, see [Troubleshooting](/using-mod-manager/troubleshooting).
