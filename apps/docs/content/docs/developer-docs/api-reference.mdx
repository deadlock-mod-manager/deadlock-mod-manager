# API Integration Guide

The [API Reference](/api) documents each HTTP route with its request and response schema and lets you send test requests. This page covers the base URL, the mod routes and the error format.

## Base URL

HTTP routes are served under `https://api.deadlockmods.app/api`. A route documented as `GET /v2/mods` is requested at `https://api.deadlockmods.app/api/v2/mods`. The OpenAPI specification is published at `https://api.deadlockmods.app/docs/openapi.json`.

## Authentication

Mod, download and status routes are public:

```typescript
const response = await fetch("https://api.deadlockmods.app/api/v2/mods");
const mods = await response.json();
```

Routes that read or change account data, such as profile backups, require a signed-in session.

### Rate Limiting

All endpoints are rate-limited to ensure fair usage:

```http
HTTP/1.1 200 OK
X-RateLimit-Limit: 100
X-RateLimit-Remaining: 99
X-RateLimit-Reset: 1640995200
```

**Rate Limits:**

- **Public endpoints**: 100 requests per minute per IP
- **Download endpoints**: 10 concurrent downloads per IP
- **Upload endpoints**: 5 requests per minute per IP (authenticated)

## Mods

The mod routes return data defined by `ModDtoSchema` and `ModDownloadDtoSchema` in `packages/shared/src/schemas/mod.schemas.ts`.

### List mods

```http
GET /v2/mods
```

Returns every mod as a JSON array. The route takes no query parameters: there is no pagination, search, filtering or sorting, so filter the array on the client. `GET /v1/mods` returns the same array.

Response, with one element shown and optional fields omitted:

```json
[
  {
    "id": "mod_01jhq6v3x9e8s7r6t5y4u3i2o1",
    "remoteId": "512345",
    "name": "Example Skin",
    "description": "A recolor for Haze.",
    "remoteUrl": "https://gamebanana.com/mods/512345",
    "category": "Skins",
    "likes": 42,
    "author": "ExampleAuthor",
    "modAuthorId": null,
    "downloadable": true,
    "remoteAddedAt": "2026-01-10T08:00:00.000Z",
    "remoteUpdatedAt": "2026-01-20T14:45:00.000Z",
    "tags": [],
    "images": ["https://images.gamebanana.com/img/ss/mods/example.jpg"],
    "hero": "Haze",
    "isAudio": false,
    "isMap": false,
    "audioUrl": null,
    "downloadCount": 1542,
    "isNSFW": false,
    "filesUpdatedAt": "2026-01-20T14:45:00.000Z",
    "createdAt": "2026-01-10T09:00:00.000Z",
    "updatedAt": "2026-01-20T15:00:00.000Z"
  }
]
```

Mod routes send `Cache-Control: public, max-age=3600`, so the list can be cached for an hour.

### Get a mod

```http
GET /v2/mods/{id}
```

Returns one mod object in the same shape. `{id}` is the GameBanana mod ID (`remoteId`), not the internal `id`. An unknown ID returns 404. `GET /v1/mods/{id}` behaves the same way.

### Mod downloads

```http
GET /v2/mods/{id}/downloads
```

Returns `{ "downloads": [...], "count": n }`. Each download has `url`, `size` in bytes, `name`, `description`, `createdAt`, `updatedAt` and `md5Checksum`. `GET /v1/mods/{id}/download` returns an array that contains only the largest file. Both routes return 404 when the mod or its files are not found.

## Desktop Integration API

### Tauri Commands

The desktop application exposes these Tauri commands for frontend-backend communication:

#### File System Operations

```typescript
// Check if game is installed
const gameInstalled = await invoke<boolean>("check_game_installation", {
  gamePath: "/path/to/deadlock",
});

// Install a mod
const result = await invoke<InstallResult>("install_mod", {
  modId: 12345,
  filePath: "/path/to/mod.zip",
  options: {
    backup: true,
    overwrite: false,
  },
});

// Uninstall a mod
await invoke<void>("uninstall_mod", {
  modId: 12345,
  restoreBackup: true,
});
```

#### System Integration

```typescript
// Get system information
const systemInfo = await invoke<SystemInfo>("get_system_info");

// Open file explorer
await invoke<void>("open_file_explorer", {
  path: "/path/to/directory",
});

// Show in file manager
await invoke<void>("show_in_file_manager", {
  filePath: "/path/to/file.zip",
});
```

#### Game Integration

```typescript
// Detect game installation
const detectionResult = await invoke<GameDetection>("detect_game_installation");

// Launch game
await invoke<void>("launch_game", {
  gamePath: "/path/to/deadlock",
  args: ["--windowed"],
});

// Get mod status
const modStatus = await invoke<ModStatus[]>("get_mod_status", {
  gamePath: "/path/to/deadlock",
});
```

### Events

The desktop application emits events for real-time updates:

```typescript
import { listen } from "@tauri-apps/api/event";

// Download progress
await listen<DownloadProgress>("download-progress", (event) => {
  console.log(`Download ${event.payload.id}: ${event.payload.progress}%`);
});

// Installation progress
await listen<InstallProgress>("install-progress", (event) => {
  console.log(`Installing: ${event.payload.status}`);
});

// Error events
await listen<ErrorEvent>("error", (event) => {
  console.error("Error occurred:", event.payload.message);
});
```

## Error Handling

Errors use oRPC's JSON body, and the HTTP status matches `status`:

```json
{
  "defined": false,
  "code": "NOT_FOUND",
  "status": 404,
  "message": "Not Found"
}
```

Invalid input returns 400 with code `BAD_REQUEST`.

### Desktop Application Errors

```typescript
interface TauriError {
  code: string;
  message: string;
  details?: Record<string, any>;
}

// Common error codes
const ErrorCodes = {

  CHECKSUM_MISMATCH: "CHECKSUM_MISMATCH",

```
