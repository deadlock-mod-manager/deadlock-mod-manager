# API Integration Guide

Deadlock Mod Manager's API supports application services such as profiles, reports, policy, server discovery, releases, and VPK analysis. The generated [API Reference](/api) is the source of truth for currently published operations.

<Callout type='warning' title='Public catalog retired'>
  The v1, v2, and legacy mod catalog, detail, archive, update-check, fileserver,
  redirect, and synchronization routes were removed on August 30, 2026. There is
  no compatibility proxy. Catalog integrations should use GameBanana directly.
</Callout>

Clients should validate all responses, use HTTPS, apply bounded retries for transient failures, and avoid attaching a stable Deadlock Mod Manager identifier to GameBanana requests.
