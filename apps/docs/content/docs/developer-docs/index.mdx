## Getting Started

### Contributing code

1. [Set up your development environment](/developer-docs/development-setup) (or use [Nix](/developer-docs/nix-development) on Linux)
2. [Understand the project structure](/developer-docs/project-structure)
3. [Read the contributing guidelines](/developer-docs/contributing)
4. Start with a good first issue on GitHub

### Understanding the system

1. [Review the project structure](/developer-docs/project-structure)
2. [Study the architecture documentation](/developer-docs/architecture)
3. [Explore the interactive API documentation](/api)

### API integration

1. [Browse the interactive API reference](/api)
2. [Read the integration guide](/developer-docs/api-reference)
3. [Join our Discord](https://discord.gg/WbFNt8CCr8) for developer support

## Key Technologies

- Desktop: Tauri v2 with a Rust backend and a React 19 frontend using TypeScript and Tailwind CSS v4
- Backend: Bun with Hono and oRPC
- Database: PostgreSQL with Drizzle ORM
- Cache and pub/sub: Redis
- Build system: Turborepo
