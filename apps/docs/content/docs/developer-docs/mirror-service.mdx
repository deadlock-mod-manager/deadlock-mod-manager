---
title: Download Redirect Service
description: Compatibility for previously issued mirror download links
---

The API returns upstream archive URLs from the synced GameBanana catalog or
from a configured download override. The download redirect service keeps
previously issued links on `mirror.deadlockmods.app` working while their
catalog entries exist.

## Download links

```http
GET /download/{modId}/{fileId}
```

Both path parameters are internal catalog IDs. The service checks that the
download belongs to the mod and responds with a temporary `307` redirect to
the stored archive URL. Clients follow the redirect to download the archive.
`HEAD` also returns the redirect. Unknown ID pairs return `404`. A catalog
refresh can replace file IDs when a submission's files change.

## Deployment

The service uses the existing mirror hostname, container, and port. It needs
access to PostgreSQL to resolve links. `GET /` and `GET /health` check database
connectivity. The legacy `GET /metrics` response reports zero active cache
files, storage, hits, and bandwidth savings.

After rollout, check `/health` on the public hostname and follow a previously
issued download link. Existing mirror objects and database records remain
available for rollback.
