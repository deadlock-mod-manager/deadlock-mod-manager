The community-run [Deadlock Modding Guides](https://deadlockmodding.pages.dev/modding-guides/) site explains how to make mods for Deadlock.

## Available Modding Guides

The site has guides for:

- Packing an addon
- Compiling UI textures
- Replacing sounds
- Importing GLTF models from Blender
- Fixing common Source 2 Filmmaker (S2FM) bugs

## Tools You'll Need

- Blender, for 3D model work and GLTF imports
- Source 2 tools, for compiling assets
- A text editor, for scripts and configuration files
