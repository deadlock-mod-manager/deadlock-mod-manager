# API Reference

The public mod catalog, detail, archive, update-check, fileserver, and manual-sync endpoints were retired on August 30, 2026. They are not proxied to GameBanana.

<Callout type='warning' title='Catalog API cutoff'>
  Integrations must use GameBanana's API directly. Current Deadlock Mod Manager
  desktop releases already do this and do not attach a stable Deadlock Mod
  Manager user identifier to those requests.
</Callout>

The generated pages in this section document the supported service endpoints that remain, including profiles, reports, feature flags, health checks, releases, and VPK analysis.

The service base URL is `https://api.deadlockmods.app`. Consult each operation page for its route, schema, and authentication requirements.
