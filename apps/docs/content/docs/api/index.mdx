# API Reference

Each endpoint page shows the request and response schema and includes a playground for sending test requests.

<Callout type='info' title='API Information'>
  Routes are served under `https://api.deadlockmods.app/api` and return JSON.
  Mod, download and status routes need no authentication.
</Callout>

## Quick Start

### Example Request

```bash
curl "https://api.deadlockmods.app/api/v2/mods"
```

### Example Response

`GET /v2/mods` returns every mod as a JSON array. It takes no pagination, search or filter parameters. One element, with most fields omitted:

```json
[
  {
    "remoteId": "512345",
    "name": "Example Skin",
    "author": "ExampleAuthor",
    "category": "Skins",
    "downloadCount": 1542,
    "remoteUpdatedAt": "2026-01-20T14:45:00.000Z"
  }
]
```

The [List Mods V2](/api/listModsV2) page lists every field.

## API Versions

New integrations should use the `/v2` routes. The `/v1` routes remain available: `GET /v1/mods` and `GET /v1/mods/{id}` return the same data as their v2 equivalents, and `GET /v1/mods/{id}/download` returns only the largest file of a mod.

## Rate Limits

All API endpoints are rate-limited to ensure fair usage:

- **Standard Endpoints**: 100 requests per minute per IP
- **Download Endpoints**: 10 concurrent downloads per IP
- **Bulk Operations**: 5 requests per minute per IP

Rate limit information is included in response headers:

```http
X-RateLimit-Limit: 100
X-RateLimit-Remaining: 99
X-RateLimit-Reset: 1640995200
```

## Error Handling

Errors use oRPC's JSON body, and the HTTP status matches `status`:

```json
{
  "defined": false,
  "code": "NOT_FOUND",
  "status": 404,
  "message": "Not Found"
}
```
